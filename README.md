# سَنَد الأكاديمي — النسخة الشخصية العامة (v5)

هذه النسخة مشتقة من v4 ومعدّلة لتعمل دون حسابات أو اشتراكات أو بوابات دفع أو PostgreSQL. الموقع متاح عبر الرابط العام، لذلك يستطيع أي شخص يملك الرابط استخدام واجهة الفحص.

## ما الذي يعمل؟
- واجهة عربية متجاوبة للهاتف والحاسوب.
- مقارنة النصوص مع ملفات TXT وDOCX وPDF التي تضيفها أنت إلى قاعدة المصادر.
- استبعاد الاقتباسات وقائمة المراجع وإعداد طول N-gram.
- بحث ببليوغرافي عبر OpenAlex (بيانات وصفية وليست كشف استلال).
- موصل اختياري لكاشف AI خارجي. إذا لم تضبط `AI_DETECTOR_URL` فلن يعرض النظام نسبة وهمية.
- لا يتم إنشاء حسابات ولا تخزين سجل مركزي لفحوصات الزوار.

## حدود مهمة
- نسبة التشابه محسوبة فقط مقابل قاعدة المصادر التي تضيفها؛ لا تتصل المنصة بـ Turnitin أو iThenticate ولا تفحص كامل الإنترنت.
- كشف AI يحتاج خدمة خارجية مستقلة ومدرّبة ومقيّمة على العربية.
- لا ترفع أبحاثاً سرية: الرابط عام، ونص الفحص يُرسل إلى خادم الاستضافة.
- توجد حدود طلبات لمنع الإساءة: 5 فحوصات تشابه كل 10 دقائق لكل عنوان IP، و3 تحليلات AI كل ساعة لكل IP. هذه ليست حماية خصوصية أو دخولاً خاصاً.
- على Render Free نظام الملفات مؤقت؛ قاعدة المصادر التي ترفعها من الواجهة قد تُفقد عند إعادة التشغيل أو إعادة النشر أو إيقاف الخدمة. للحفاظ عليها يلزم Render Web Service مدفوع مع Persistent Disk وتعيين `DATA_DIR=/var/data`. راجع وثائق Render.

## النشر عبر GitHub + Render
GitHub Pages لا يشغّل Node.js؛ هو لنشر الملفات الثابتة فقط. هذه النسخة تحتاج Express API، لذا ارفع المستودع إلى GitHub ثم اربطه كـ Web Service في Render. Render يدعم نشر Node.js من مستودع Git وإعادة النشر عند تحديث الفرع.

1. أنشئ مستودع GitHub جديداً باسم `sanad-academic-personal`.
2. ارفع محتويات هذا المجلد إلى جذر المستودع، وليس ملف ZIP نفسه. لا ترفع `.env` أو أسراراً.
3. افتح Render ثم New → Blueprint، واربط مستودع GitHub. سيقرأ `render.yaml`. أو اختر New → Web Service واضبط: Build `npm install` وStart `npm start`.
4. في Environment أضف `ADMIN_TOKEN` بقيمة عشوائية طويلة. احفظها في مكان آمن؛ تحتاجها عند إضافة مصادر المقارنة. لا ترسلها لأحد ولا تضعها داخل HTML.
5. انشر الخدمة وانتظر نجاح Build وDeploy. افتح رابط `https://اسم-الخدمة.onrender.com`.
6. اختبر `/api/health` وتأكد أن الاستجابة تحتوي `ok: true`.

## إضافة المصادر
من تبويب «قاعدة مصادر المقارنة» ارفع ملفاً، وأدخل رمز `ADMIN_TOKEN` في الحقل المخصص. لا ترفع ملفات لا تملك حق استخدامها.

## إعداد كاشف AI
أضف في Render Environment: `AI_DETECTOR_URL`، ويمكن إضافة `AI_DETECTOR_API_KEY`. يجب أن يستقبل endpoint JSON بالشكل `{ "text": "...", "language": "ar", "task": "ai_generated_text_detection" }` ويرجع `{ "ai_probability": 0.73, "model": "Arabic-detector-v1" }`. لا يوجد نموذج AI مضمّن في المشروع.

## التشغيل المحلي
يتطلب Node.js 20 أو أحدث:
```bash
npm install
cp .env.example .env
npm start
```
افتح `http://localhost:3000`.
